# Page Specification — Finance (財務管理)

## Route: `/finance`

### Sub-routes
| Path | Label | Description |
|------|-------|-------------|
| `/finance/invoices` | 發票列表 | 所有發票管理 |
| `/finance/payments` | 付款追蹤 | 收付款記錄 |
| `/finance/credit-cards` | 信用卡管理 | 公司信用卡 |
| `/finance/by-company` | 按公司查看 | 公司財務分離 |

### 發票操作
- 記錄付款 (partial / full)
- 上傳收據
- 發送催款提醒
- 標記已付款

### 狀態色彩
| 狀態 | 顏色 | Badge |
|------|------|-------|
| unpaid | Slate | 未付款 |
| partial | Amber | 部分付款 |
| paid | Green | 已付款 |
| overdue | Red | 逾期 |
