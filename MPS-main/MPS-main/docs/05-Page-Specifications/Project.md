# Page Specification — Project (專案策劃)

## Route: `/project`

### Sub-routes
| Path | Label | Description |
|------|-------|-------------|
| `/project/list` | 項目列表 | 全部項目（表格/卡片） |
| `/project/new` | 新增項目 | 三步驟建立流程 |
| `/project/:id` | 項目詳情 | 單一項目資訊 |
| `/project/:id/gantt` | 甘特圖 | 排程視圖 |
| `/project/:id/kanban` | 看板 | 任務拖拉 |
| `/project/:id/budget` | 預算 | 預算對比 |
| `/project/:id/year-plan` | 年度計劃 | 目標達成 |

## 數據交互

| 操作 | API | Table |
|------|-----|-------|
| 項目列表 | SELECT | projects JOIN companies, brands |
| 新增項目 | INSERT | projects |
| 更新狀態 | UPDATE | projects.status |
| 任務拖拉 | UPDATE | project_tasks.status |
| 甘特圖 | SELECT | project_tasks WHERE project_id |
| 預算 | SELECT | projects.budget_total, budget_used |
