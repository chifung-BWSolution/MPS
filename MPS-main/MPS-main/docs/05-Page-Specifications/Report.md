# Page Specification — Report (報表分析)

## Route: `/report`

### Sub-routes
| Path | Label | Description |
|------|-------|-------------|
| `/report/performance` | 績效報告 | KPI + 產出統計 |
| `/report/manhours` | 工時報告 | 工時分析 |

## Performance Sub-page (績效報告)

### 6 KPI 卡片

| KPI | 計算方式 | 對比 |
|-----|---------|------|
| 活躍項目數 | COUNT(projects WHERE status='active') | vs 上月 |
| 完成項目數 | COUNT(projects WHERE status='completed' AND this_month) | vs 上月 |
| 文章產出 | COUNT(articles WHERE publish_date = this_month) | vs 上月 |
| 影片產出 | COUNT(videos WHERE status='published' AND this_month) | vs 上月 |
| 社交帖文 | COUNT(social_posts WHERE status='published' AND this_month) | vs 上月 |
| 人均工時 | AVG(day_reports.total_hours) | vs 上月 |

### 篩選器
- 公司 / 品牌
- 日期範圍（預設本月）
- 部門 / 特定人員

### 圖表

1. **月度產出趨勢** — 折線圖 (文章/影片/社交帖文 x 月份)
2. **項目完成率** — 環形圖 (completed / total)
3. **各品牌績效對比** — 分組長條圖

## Manhours Sub-page (工時報告)

### 主要圖表

1. **橫向疊加長條圖** (人員 x 工時)
   - 每人一行
   - 按 task_category 顏色堆疊
   - 可切換日/週/月

```
陳小華  ████████████████████░░░░░ 8.5h
        [網站][文章][SEO][會議]

李美玲  ██████████████████░░░░░░░ 7.5h
        [設計][社交][影片]

王小明  ████████████████████████░ 9.0h (OT)
        [文章][文章][社交][會議]
```

2. **環形圓餅圖** — 工時按類別分布
   - 顯示各 task_category 佔比
   - 按公司/品牌篩選

3. **同事工時排行** — 排行榜
   - 本月累計工時
   - 平均每日工時
   - OT 天數

4. **人力效能統計**
   - 每小時產出量 (文章/頁/影片)
   - 人均成本估算（如設定薪資）

### 匯出
- [匯出 PDF] — 生成格式化報告
- [匯出 CSV] — 原始數據
