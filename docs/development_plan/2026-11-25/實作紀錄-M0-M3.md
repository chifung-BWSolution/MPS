### 6.1 AI 生成（2026-11-25 追加）

- 新增 `_shared/contentSocialLlm.ts`：xAI Grok 封裝，一次呼叫產「長文 + 各平台導流」，嚴格 JSON。
- 新增 migration `20261126130000_content_social_llm.sql`：`content_social_posts.generator`（template／grok）。
- `content-social` 生成流程：Grok 優先 → 失敗／超時 → 模板 fallback；成功寫 `content_llm_usage`（`use_case=social`）。
- 模型選擇實測：`grok-4.5`（推理型）30–60 秒仍超時；`grok-4.20-non-reasoning` 回傳非合法 JSON；**`grok-4.3` 穩定**，故以 `CONTENT_SOCIAL_MODEL=grok-4.3` 固定，不動廣告顧問的 `GROK_MODEL`。
- 可靠性：LLM 模式下 `auto_tick` 每輪限 1 個熱點 + 95 秒預算；`review`／`mark` 流程不變。
- 只貼標題的熱點：生成後用摘要回填 `content_hot_events.summary`，卡片不再只有標題；既有 NULL 以 `scripts/content-social-backfill.sql` 補齊。
- 實測：新建熱點 → 2 批（`generator=grok`、1,330／1,508 字、各平台文案）；舊批次仍為 `template`，UI 以「AI 生成／模板草稿」標示。
- 資料修復（2026-11-25）：有一個測試熱點因 PowerShell 送中文 JSON 時編碼錯誤，標題／摘要被寫成 `?????`；已用 `scripts/content-social-repair.sql` 修正，並把種子資料中不存在的 `/hot/...` 原文連結設為 NULL（點擊不會再開到 404）。**日後建立熱點請用 UI 或 Node（UTF-8），不要用 PowerShell `Invoke-RestMethod` 送中文 JSON。**
