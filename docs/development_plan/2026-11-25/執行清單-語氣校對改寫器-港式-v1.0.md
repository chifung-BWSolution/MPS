## 已知限制

1. 這是規則式校對輔助，不是 LLM 全文重寫；未收錄的詞會保留，靠標色與清單人工覆核。
2. 簡→繁只自動處理無歧義字；`发／后／里／干／台／面／只` 等歧義字用多字詞規則，處理不到時只提醒。
3. 詞表是種子版本（約 420 條），不是完整香港粵語詞典；每條有 `id`／`note`，可獨立增刪。
4. 不持久化、不存歷史；重新整理後要重新貼入。
5. 英文商務版只有入口提示，未實作。
6. 平台 hashtag 是規則式主題標籤，不是即時熱門標籤。
7. 全量 `tsc --noEmit` 仍有既有錯誤（行銷、財務、Readdy、內容自動化等），與本功能無關；新檔案零錯誤。
